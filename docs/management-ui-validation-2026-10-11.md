# 管理控制台与历史清理验证

> 历史记录 / Historical record: 本文保留当时构建、版本及 PASS/FAIL/未运行结论。当前 2.3.0 的使用说明见[文档入口](README.md)，发行资格见[2.3.0 验证](validation-v2.3.0.md)。

日期：2026-10-11。此记录对应当前工作区源码，属于未发布实现，不代表 2.2.4 发行二进制。

## 实现范围

- Go 程序通过 `go:embed` 提供原生 JavaScript 控制台，无前端运行依赖或构建步骤。
- 管理／合并监听器及分片 router 提供 `/ui/`；数据监听器继续隔离管理界面。
- 中英文导航、表单、提示和操作即时切换，支持浏览器语言初始选择和手动选择持久化。
- 覆盖数据／关系浏览、游标分页、查询／计划／保存查询、模型、租户、索引、任务／备份、
  接入／导入／死信、来源治理／配置、诊断及集群 API。
- 请求仍通过原有 API 和网关授权。入口地址和语言可持久化，令牌仅保存在页面内存。
  请求不自动重试，破坏性变更要求资源 ID 确认，恢复默认预演。

## 实际验证

Linux 服务和 Go 检查使用 OrbStack Ubuntu、linux/arm64、Go 1.25.0。
Chrome 使用本机现有工具，没有安装浏览器自动化框架。服务采用隔离的临时本地数据目录；
验证未使用项目原有数据库目录。

| 检查 | 结果 |
| --- | --- |
| 当前工作区 `CGO_ENABLED=0 go build -mod=readonly -buildvcs=false ./cmd/graphdb` | PASS |
| `go test -mod=readonly ./...` | PASS；包括 HA、HTTP、存储、复制、查询、SDK 和工具包 |
| `go test -mod=readonly -race -timeout 20m ./...` | PASS；HA 包约 454 秒，存储约 187 秒 |
| `go vet -mod=readonly ./...` | PASS |
| `node --test internal/adminui/console_test.mjs` | PASS，4 个边界／回归检查 |
| Python SDK 单元检查 | PASS，11 个测试，其中 1 个依赖在线服务的检查跳过 |
| 真实 TLS NGINX 网关门禁 | PASS，22 个请求，包括 UI 静态资源、编码路径、角色及租户头隔离 |
| 工作区重复文件检查与 `git diff --check` | PASS |
| GitHub／GitLab YAML 解析及 GitLab job 依赖 | PASS；未触发远端 CI |

JavaScript 检查保护大整数 token 保真、令牌不持久化、入口／租户／认证头选择、
不确定变更不自动重试，以及 NDJSON 导出的逐行内容。

Chrome 实际走通：

1. 创建 `demo` 租户，通过请求预览写入实体和关系，读取到发布后的版本和数据。
2. 执行 JSON DSL 和 GraphQL 查询；保存查询后在列表读回。
3. 新建普通和唯一索引；后台索引任务显示成功。
4. 启动压实任务、通过本机文件选择器上传 JSONL；两项任务均到达成功终态。
5. 创建实体类型及关系字段模型，列表读回定义；来源策略保存后读回。
6. 修改未保存配置后切换语言，文本保留；离开时出现确认，取消后继续编辑。
7. 在另一租户的 30 条实体中按 25 条分页，第二页为 5 条，返回上一页为 25 条；
   切回 `demo` 后只显示该租户的实体。
8. 查看关系图和邻居图，点击邻居节点读回实体详情。
9. Chrome 实际下载 NDJSON 文件，核验 7 行、4 个实体、1 条关系。
   浏览器工具的下载事件等待超时，但 Chrome 已生成文件，文件内容已独立核验。
10. 保存并测试连接；通过当前请求认证读取 API 参考；未配置集群入口时显示配置说明。
11. 中文手动选择在刷新后保留；英文／中文界面、桌面与 390×844 窄屏导航和查询均验证。

最终页面标题为 `GGraphDB Console`，页面内容非空，无框架错误浮层，
最终 Chrome 检查没有相关 error/warn 日志。窄屏数据表在自身容器滚动：
页面宽 390、表格容器宽 352、表格内容宽 440；查询页的页面宽也为 390。
