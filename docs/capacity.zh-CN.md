# 本地磁盘容量与测量

[English](capacity.md)

本版采用单进程、多客户端、多租户并发。容量取决于内存、本地磁盘延迟、字段
宽度、关系密度和索引数量，不能只按实体数判断。写缓存与读图缓存都有容量
上限；图超过预算时会绕过缓存加载。需要稳定查询延迟时，应按工作负载配置
两种图缓存。

## 验证流程

- `scripts/capacity_baseline.sh`：短时 API 检查和有限批次负载。
- `scripts/local_disk_benchmark.py`：固定数据量、定时比较 `ffa85414` 的 S3
  模式、本地模式与新实现。需预构建基线/候选/压测二进制，并使用隔离的 Linux 卷。
- `GRAPHDB_GATE_SOAK=1 RELEASE_GATE_SKIP_STATIC=1 scripts/release_gate.sh`：
  30 分钟、4 个写入客户端、16 个查询客户端，同时执行 compact、GC 和索引重建。
  该 CMDB 数据字段较多，读写图缓存各配置 2 GiB，写客户端间隔 5 秒以控制数据增长。

持久化和配置详见[本地磁盘运维](local-disk.zh-CN.md)。对照测量覆盖 10,002 和
100,002 个实体，预热 1 分钟、测量 5 分钟，轮换服务顺序重复 3 次。保存已发布
吞吐、延迟分位数、WAL 受理到可读延迟、RSS/CPU、进程 I/O、GraphDB fsync 次数和
文件句柄数。MinIO 仅用于历史基线，不是本版运行依赖。

进程冷启动和操作系统页缓存状态分别说明。共享 OrbStack 不是独占硬件，应
记录波动，噪声较大的结果标记未定。历史分布式性能报告不代表本地磁盘版性能。
