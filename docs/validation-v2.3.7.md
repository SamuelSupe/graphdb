## 修复范围

WAL 分组及 PREPARED 超限拆分、生成号超时、租户规模内存预留与追平重试、catalog 单调发布、
拆分等值／范围查询／负零／非标量一致性、旧实体分页、日期／毫秒时间过滤、可重试快照、Drain 自动移交、
租户生命周期及恢复来源约束、隔离恢复确认、解码前准入、监控租户登记、未知存储错误脱敏、Compose 回环。

WAL 完整帧损坏不自动截断；平台跨租户迁移保留。运行恢复的隔离确认只防误操作，不替代网络隔离。
已终态失败的旧 batch 需要对账后用新身份重放。旧 catalog 可读，范围扫描可能保守回退。
