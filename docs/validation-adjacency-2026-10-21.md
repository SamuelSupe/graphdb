# 邻接范围读取与小页合并验证（2026-10-21）

本次提交实现邻接 ID 树与局部合并，仅交付源码，不创建发行标签或替换已有资产。启用与格式边界见[实现说明](entity-range-paging-implementation.zh-CN.md#邻接-id-树与局部合并)。两个布局写开关均默认关闭。

## 修复前复现

在 OrbStack Ubuntu、Go 1.26.7、`GOMAXPROCS=2` 下连续两次运行回归：

- 同一逻辑桶 8192 条边，目标节点只有一条邻边，正向及反向均读取 8 个完整边页，超过一页上界。
- 一个 4096 实体的桶删除至 800 行、每个原页留下 200 行后，仍保留 4 个非空页，未进行局部合并。

对应测试分别为 `TestSparseRangeAdjacencyDoesNotReadUnrelatedPayloadPages` 和 `TestRangeDeleteMergesNonemptyNeighborPages`。

## 成本与兼容边界

| 验证 | 实际结果 |
| --- | --- |
| 桶内 1024／8192／65536 条边，固定度数 0／1，正反向冷／热读取 | 完整边页读取分别为 0／最多 1，未随无关边增加 |
| 邻接树 1024／10000／100000 项的单键修改 | 实际 PUT 次数及字节数受叶页和祖先路径上界约束，未重写全树 |
| 边字段变更，ID／端点／类型不变 | 邻接根完全复用，邻接对象 PUT 为 0；完整边页重写不超过 1024 行 |
| 删除、跨桶／关系变化、自环及邻接 seek | 数据、方向与顺序断言通过 |
| 非空小页合并、跨路由节点的邻接叶合并 | 局部收敛，旧根仍可读，单个后台片最多发布一对页 |
| 编码名额繁忙、取消与期限 | 单机可选合并跳过；复制路径在原期限内等待，取消后不遗留名额与维护预算 |
| 后台目录追赶的 full-build fallback | 不隐式创建邻接根；显式重建才转换无根桶，修复前该边界另行复现两次 |
| 页／树写失败、目录 CAS 失败、发布后报错 | 已提交图与旧根保留，索引失败不改变受理结果 |
| 固定旧视图与 GC、缺失树根／后续密集数据页 | 旧视图可读，释放后可回收；损坏返回错误，不静默返回空或在部分输出后回退 |
| 旧单文件／pack 与无邻接根的范围目录 | 现有读取路径继续支持；迁移与降级测试通过 |
| 旧 `ListEdges` 游标及 Type／Source／From／FromShard | 迁移、删除合并后保持原快照顺序与全部 ID；过期快照报错 |

完整数据页的平面目录加载与发布仍随页数增长。上述上界针对邻接树及触及的数据页，不表示整个提交或首次目录读取为恒定成本，也没有推导吞吐提升倍数。
