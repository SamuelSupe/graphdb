## 追加复核：F7、F8、F11

追加审查收回了原来范围过窄的结论，三项均补充了失败复现：

- F7：真实三副本中，300 字符的 idempotency_key 触发文件名过长，已提交应用失败，
  请求返回 raft_unavailable。现在路径组件在 I/O 前校验为 400；确定性 HTTP 5xx 完整回滚后
  记录失败响应，下一条继续。批量回归保护成功邻居；真实文件错误仍停在原 checkpoint，修复后重放。
- F8：已确认前缀后追加未确认的全零／CRC 坏尾，原版拒绝恢复。新增可验证持久化边界后，
  仅裁掉边界之后的坏尾。边界写失败不返回确认；边界损坏、已确认短帧或完整坏帧及 legacy
  无法判定的完整坏帧均保留证据并拒绝启动。轮转／清理前推进边界，备份保留边界文件。
- F11：旧配置记录不含 tenant_id 时，大小写别名可读取配置，已在不区分大小写 APFS 上复现三轮。
  文件层现检测卷能力并验证目录实际拼写；不依赖记录内的身份字段。

追加修复的全量验证和远程 CI 尚待完成；不把此前提交的 CI 成功记为这些追加修改已验证。

## 新增性能／稳定性审查（进行中）

此前 GitHub main `14a1235` 的六个 CI jobs 均成功；下列追加修改按用户要求先作为源码检查点提交，不受该轮 CI 结果覆盖。v2.3.9 未打标签，v2.3.8 标签与资产不变。

| 报告 | 当前结论／进展 |
| --- | --- |
| 1 固定 64 桶写放大 | 确认代码整桶重建；有界写入回归仍失败，尚未修复，阻止发行 |
| 2 毒性租户钉住 WAL | 三轮复现：第 10 个健康批次 WAL 满；检查点修复后三轮健康 80 批并修复故障、重启恢复成功；PREPARED 折叠、检查点损坏拒绝已回归 |
| 3 默认快照 | 应用和 Raft run 是两个 goroutine，原报告心跳描述过宽；三副本阻塞构建时提案应用超时已复现。候选复用后台文件构建、接收端保存大负载、run 仅处理描述符，三轮 race 通过；新增默认大小预算孤儿文件回归也已修复 |
| 4 match 深分页 | JSON／stream 全量候选获取已三轮复现；等值与范围／前缀访问改为游标定位、合并共享 postings，专项三轮 race 通过 |
| 5 neighbors 回退分页 | 第二页重新扫描全邻接，突破小成本预算，三轮复现；新增物化邻接顺序缓存及定位，成本和 storage-copy 失效回归三轮 race 通过 |
| 6 ReaderCache TTL | TTL 为零截止时间已三轮复现；恢复 TTL，专项三轮 race 通过；2.x 仍不支持多进程共享目录 reader 部署 |
| 7 导出锁 | 网络 writer 阻塞时持全局导出锁已三轮复现；构建和网络输出移出锁，专项三轮 race 通过，关闭／取消路径同步处理 |
| 8 全量重建 | 所有 postings 同时驻留确实存在，现逐字段写入释放、复用 kind 顺序、合并重复定义；流式／原输出等价测试三轮 race 通过。字段值输出规模本来就与索引字段总量相关，不承诺消除这个下界 |
| 9 目录锁 | 既有目录校验原全局串行；改为共享读取，创建与失败 fsync 重试仍排他。17 并发 metadata walk 基准三次中位数约 3.69µs → 0.89µs；不是整机吞吐测量。APFS 别名回归三轮 race 无跳过通过 |
| 10 peerMu 下 IO | 阻塞成员持久化时 peer 读取超时已三轮复现；事务移出 peerMu，退役表持久化后缓存，专项三轮 race 通过。Raft 仍需要持久化配置，这不消除慢磁盘的一致性等待 |
