## 修复及回归

| 条目 | 行为与验证边界 |
| --- | --- |
| F9 恢复来源 | 默认要求备份来源等于目标；平台迁移显式声明来源；受限租户不能覆盖；legacy key/记录身份、local stage 和演练保持一致 |
| F10 浏览器写入 | 跨站 Origin、null Origin、跨站标记、表单和 text/plain 写入被拒；同源、代理端口、Follower/Router 转发及原有 JSONL/CSV 导入有效 |
| L2 准备错误 | 未分类错误不再终态失败；释放应用读锁后公平重试，故障解除可完成任务；已知永久错误仍失败 |
| L5 结果记录错误 | 图已发布后的 commit/ingest 错误隐藏路径，保留 500 / internal_error / retryable:false 和缓存失效 |
| L6 游标 | 数字游标必须带匹配的 min_version；编码游标必须含版本；错误版本被拒 |
| WAL 等待 | fatal/强制关闭会唤醒等待；accepted 批次重启后恰好恢复一次 |
| 延迟索引预算 | 排队期间图增长后重验预算；释放不足的预留后重新准入；超预算图保持独占预算 |

上述真实缺陷先在原生产代码上复现，再修复。新浏览器防护曾暴露代理 Host 重写和导入媒体别名
兼容性缺口，均先用稳定测试复现后修复。相关 API、SDK、部署示例与文档同步更新。

## 保留的保护与未复现项

- F7：应用 5xx 的回滚与 checkpoint 保持不变；修复故障后同一已提交索引可以重放。
  不能把副本本地存储错误独立转换成跳过日志。确定性故障仍可能停止应用，需修复后恢复。
- F8：完整坏 CRC/全零 WAL 帧可能已被确认；保留原字节并拒绝启动，已有半帧尾截断行为保留。
- F11：既有身份检查拒绝大小写别名；在 OrbStack 访问不区分大小写 APFS 卷上实跑三轮通过，未跳过。

## 已完成的本地验证

OrbStack Ubuntu arm64：全量 unit 和 vet 通过；全量 race 通过，最终 HTTP/SDK 改动再次跑整包 race；
核心 HA/HTTP/storage/query 场景三轮 race，WAL/索引预算场景五轮 race 通过。
慢选举分片迁移／取消场景三轮 race 通过（93.94、89.61、83.37 秒）。测试等待预算现依据配置
覆盖两轮随机选举；生产选举参数与一致性断言不变。

真实 direct/WAL HTTP、负载、重启快照一致性通过。MinIO/S3 门禁覆盖分片上传、取消／损坏拒绝、
新目录恢复、覆盖、演练、自动备份重启及换主恢复。Go 1.26.7 构建的最终本地镜像经 TLS NGINX
27 项请求通过；本机 Chrome 同源租户创建成功。Python SDK 12 项通过，1 项可选 live-API 检查跳过，
真实 HTTP SDK 路径由集成门禁另行执行。

这些是本地审查证据，尚不等于本版确切标签资格。本版没有新增生产容量、秒级尾延迟消除、
物理跨主机故障域、断电或日级稳定性保证。最终发布门禁和下载核验结果将补充于此。
