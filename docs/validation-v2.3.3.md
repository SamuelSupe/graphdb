# GGraphDB v2.3.3 失败候选记录

**NOT_RELEASED**：标签 `v2.3.3` 保留在 `bceffaf5e2bb21643dbf9496078a94f567c63c45`，未创建发行版。
[标签流水线](https://github.com/SamuelSupe/graphdb/actions/runs/39255915387) 的 Raft 滚动门禁失败：
单组三副本 v2.3.0 → v2.3.3 滚动及持续 direct/WAL 请求已通过，随后分片集群在
`docker compose up` 启动阶段退出，未进入分片滚动验证。原脚本未保留该命令的 stderr，
所以确切 CI 触发原因仍未证实，不将其归因为已确认的生产数据或兼容缺陷。

门禁默认端口 56080–57402 落在本次 OrbStack Linux 的临时端口范围 32768–60999。
已独立复现：出站客户端占用 57202 时，Docker 发布同一地址端口报 address already in use。
后续版本将默认监听端口移到 26080–27402，并在命令失败时输出捕获的 stdout/stderr，
不隐藏错误或增加盲目重试。该端口风险确实存在，但旧 CI 是否恰好由此触发无法补证。

主分支六项 CI 已全部通过：普通测试、vet、全仓 race、SDK、S3、网关、单机、容器及非长测 Raft。
本机 HA 全量 race 75 个测试事件通过，耗时 482.264 秒。
标签流水线的单机集成、S3、网关通过；剩余运行在候选失效后停止，未完成长测不算通过。
所有原标签与日志保留，无门禁豁免。后续独立验收见 [2.3.4 验证](validation-v2.3.4.md)。
