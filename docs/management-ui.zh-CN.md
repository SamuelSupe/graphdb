# 管理控制台

**GGraphDB 2.3.0** · [English](management-ui.md) · [文档中心](README.zh-CN.md) · [API 指南](user/README.zh-CN.md)

控制台内嵌于 Go 程序，支持英文和简体中文。运行时无需 Node、npm、前端构建或
独立 UI 服务；此前发行的 2.2.4 二进制不包含此功能。

[打开控制台](#打开控制台) · [页面地图](#页面与能力) · [租户分页](#大量租户) · [连接设置](#连接与授权)

## 打开控制台

1. 在仓库根目录启动服务：

   ```sh
   go build -o bin/graphdb ./cmd/graphdb
   GRAPHDB_ADDR=127.0.0.1:8080 GRAPHDB_DATA_DIR=./.graphdb bin/graphdb serve
   ```

2. 访问 **[http://127.0.0.1:8080/ui/](http://127.0.0.1:8080/ui/)**。
3. 顶部选择租户，侧栏底部切换语言。首次语言跟随浏览器，手动选择保存在本地。

| 监听方式 | UI 入口 |
| --- | --- |
| 合并监听 | 服务地址的 `/ui/` |
| 设置 `GRAPHDB_ADMIN_ADDR` 的分离监听 | 管理端口的 `/ui/`；数据端口返回 404 |
| `serve-router` | 路由地址的 `/ui/` |

## 页面与能力

| 页面 | 主要流程 |
| --- | --- |
| 概览 | 当前状态、磁盘、存储、并发、任务和版本图表；诊断放在“查看”弹窗 |
| 数据浏览 | 实体／关系过滤、游标分页、详情、版本检查后的编辑／删除、邻居、受限关系图和快照导出 |
| 查询工作台 | JSON DSL、GraphQL 和旧 DSL；示例、计划／分析、表格／JSON／图结果、下一页、保存查询和当前进程的查询取消 |
| 数据模型 | 查看、新建、编辑和删除实体类型、关系类型及关系字段模型 |
| 租户 | 创建、编辑、选择、启用／停用、克隆、软删除和永久清理 |
| 索引 | 创建／删除、异步重建、定义、目录和健康 |
| 任务与备份 | 查看／过滤／取消／重试；备份、恢复／演练、审计、恢复提交、修复、清理、GC 和自动备份状态／重置 |
| 数据接入 | 原子提交、采集批次、CSV／JSONL 导入、采集器／批次状态、死信和重放 |
| 治理与配置 | 来源策略、租户配置和存储用量 |
| 集群 | 分片注册／摘流／恢复／注销；租户分配／迁移／取消；路由摘流／恢复；私有 Raft 状态、升级、成员变更、交接、屏障和摘流／恢复 |
| 连接设置 | 分别配置数据、管理、路由和私有 Raft 入口与令牌 |

图表使用当前 API 快照，在刷新或切换租户后更新。

| 图表 | 范围与含义 |
| --- | --- |
| 健康／就绪 | 本地实例状态 |
| 磁盘 | 数据文件系统的已用和可用空间 |
| 租户存储 | 最大的六类存储，其余分类合并展示 |

## 编辑与查看记录

记录使用分组属性、带类型的字段摘要、表格、状态和任务进度／时间线。
实体／模型编辑、写入、标签／元数据、任务参数及治理配置使用结构化表单，可重复添加字段。

| 操作 | 行为 |
| --- | --- |
| 添加字段或数组项 | 使用空白／默认值，不复制已有记录 |
| 使用高级 JSON | 支持复杂／未知字段；切换视图保留已有值和大整数 |
| 提交无效字段 | 字段重名或值与所选类型不符时阻止提交 |
| 查看原始响应 | JSON 默认收起；查询的显式 JSON 结果视图仍可用 |
| 使用长弹窗 | 内容单独滚动，标题和操作按钮保持可见 |
| 切换标签 | 支持方向键、Home 和 End |

控件、提示和说明为双语；API 标识符、自定义字段名及原始数据保持原文。

### 完成一次操作

1. 提交前核对界面展示的目标与请求内容。
2. 破坏性操作输入资源 ID 确认；恢复默认预演。
3. HTTP 202 表示受理，检查任务或 WAL 状态后判断是否完成。

请求不自动重试，超时后先核对服务端状态。停止浏览器等待不保证服务端取消，
请到相关进程的“运行中查询”执行取消。部署和备份要求仍适用，不支持的操作显示后端错误。

## 大量租户

| 入口 | 搜索与页大小 |
| --- | --- |
| 顶部切换器 | 服务端 ID 搜索，每次加载 20 条 |
| 租户表格 | 默认 25 条，可切换 50／100 条，支持 ID 搜索和前后翻页 |
| 集群归属 | 服务端 ID 搜索，每页 25 条；分片页不获取全部归属 |
| 历史发现 | 租户页显式开启，扫描存储对象；在该页选择发现的租户 |

刷新和语言切换保留筛选／分页状态，切换租户会提示放弃未完成的编辑。
搜索匹配 **ID，不匹配名称**。正常导航只读取当前页的元数据和 manifest。

### API 分页契约

```http
GET /v1/tenants?limit=25&q=team
GET /v1/cluster?limit=25&q=team
```

| 参数／响应 | 契约 |
| --- | --- |
| `limit` | 1–200；只传 `q` 或 `cursor` 时默认 50 |
| `q` | 租户 ID 子串搜索 |
| `next_cursor` | 最后一个租户 ID；下一页将其作为 `cursor`，保留相同搜索条件 |
| 租户响应 | `tenants`、匹配的 `total` 和可选 `next_cursor` |
| 集群响应 | 同样限制目录的 `tenants` 映射 |
| 无分页参数 | 保留原来的完整响应 |

分页读取实时数据，不提供快照隔离。ID 注册表／集群目录仍整体读取：分页约束详情
I/O 和浏览器渲染，不能消除注册表存储本身的成本。示例见[租户 API](user/tenant-config.zh-CN.md)。

## 连接与授权

| 部署 | 连接配置 |
| --- | --- |
| 合并监听 | 数据与管理 API 均使用页面同源地址 |
| 分离监听及同源网关 | 数据入口为网关地址；管理入口为 `<网关地址>/admin` |
| 路由／私有 Raft | 单独配置地址和令牌；Raft 还需集群 ID |
| 跨域网关 | 配置 CORS／预检，允许 `Authorization`、`Content-Type`、`X-Tenant-ID` 和 `X-Raft-Cluster` |

[网关示例](../deploy/nginx/graphdb.conf.example)将 `/admin/ui/` 静态资源转发至
`/ui/`，`/admin/v1/...` 仍要求 operator/admin 授权。支持同源会话 Cookie 和
输入的 Bearer 令牌；数据库不会新增宽松跨域策略。

控制台不新增认证系统、任意地址服务端代理或宽松角色，也不公开私有 API。
私有接口通过已授权管理网络／网关访问；需要保护 UI 本身时，在静态路由接入会话登录。
详见[生产安全](security-deployment.zh-CN.md)。

## 设置与草稿保存

| 状态 | 保存范围／行为 |
| --- | --- |
| 入口、租户、语言 | 保存在本地 |
| 令牌 | 仅内存保存，刷新页面即清除 |
| 查询草稿 | 当前页面生命周期，各语言独立保存；点击“载入示例”后才替换内容 |
| 接入草稿 | 当前页面生命周期，有效草稿保留；字段／JSON 未完成时阻止切换标签 |
| 配置编辑 | 放弃更改前提示 |
| 连接分组 | 基础 API 与可选路由／Raft 分组；已配置的可选入口自动展开 |

## 展示与导出限制

| 领域 | 限制 |
| --- | --- |
| 关系图 | 只展示返回数据，最多 100 个节点和 200 条边，不代表租户完整图 |
| 数值精度 | 当前 Chrome 原生无损解析 API 整数；精度敏感的大字段值按 API 契约使用字符串 |
| 浏览器导出 | 使用内存；大规模导出使用 CLI 或流式客户端 |

浏览器无损解析无法恢复后端数值字段已经损失的精度。

## 开发

`internal/adminui/static/` 源码由 `go:embed` 内嵌，修改后重新构建和重启。

```sh
node --test internal/adminui/console_test.mjs
go test -mod=readonly ./internal/httpapi ./internal/sharding
```

页面／交互使用本机 Chrome 验证，Linux 服务使用 OrbStack；静态检查不能替代运行验证。
