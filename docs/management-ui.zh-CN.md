# 管理控制台

[English](management-ui.md)

已发布的 2.3.0 在 Go 程序中内嵌英文／简体中文控制台，运行时不需要 Node、npm、前端构建
或独立 UI 服务。此前发行的 2.2.4 二进制不包含此新增功能。

```sh
go build -o bin/graphdb ./cmd/graphdb
GRAPHDB_ADDR=127.0.0.1:8080 GRAPHDB_DATA_DIR=./.graphdb bin/graphdb serve
```

打开 `http://127.0.0.1:8080/ui/`。设置 `GRAPHDB_ADMIN_ADDR` 时只有管理监听器
提供 `/ui/`，数据监听器返回 404。`serve-router` 也提供 `/ui/`。顶部选择租户，
侧栏底部切换语言；首次语言跟随浏览器，手动选择保存在本地。

## 大量租户

顶部切换器通过服务端搜索租户 ID，每次加载 20 条。租户管理表格默认每页 25 条，
可切换 50／100 条，支持 ID 搜索和前后翻页。集群租户归属也使用服务端搜索和
25 条分页；分片页不再获取所有租户归属。控制台刷新、语言切换保留列表筛选和页码；
切换租户时仍会提示放弃未完成的编辑。

正常导航和刷新不全量拉取租户，详情和 manifest 只读取当前页。租户页可显式勾选
“扫描历史租户”，该操作会扫描存储对象；发现的历史租户可直接从表格选择。搜索
匹配租户 ID，不匹配名称。

`GET /v1/tenants?limit=25&q=team` 返回 `tenants`、匹配总数 `total` 和可选的
`next_cursor`。下一页使用该最后一条租户 ID，并保持相同的搜索条件。
`GET /v1/cluster?limit=25&q=team` 同样限定目录中的 `tenants` 映射。每页范围
1–200；仅传 `q` 或 `cursor` 时默认 50 条。不传分页参数仍保持原有全量响应。分页
读取实时数据，不提供快照隔离。ID 注册表／集群目录仍会整体读取，因此本次优化
限定的是详情 I/O 和浏览器渲染量，尚未改变注册表本身的存储成本。

## 页面

| 页面 | 操作 |
| --- | --- |
| 概览 | 状态仪表、磁盘／任务环形图、存储／并发／版本条形图；诊断、流量闸门、写入代次与指标弹窗 |
| 数据浏览 | 实体／关系筛选、游标分页、详情、带版本检查的编辑／删除、邻居图、有限关系图和快照导出 |
| 查询工作台 | JSON DSL、GraphQL、旧文本 DSL；示例、计划／分析、表格／JSON／图、分页、保存查询和运行中查询取消 |
| 数据模型 | 实体类型、关系类型及关系字段模型的查看／新建／编辑／删除 |
| 租户 | 服务端分页与 ID 搜索、创建／编辑／选择、启用／禁用、克隆、软删除和永久清理 |
| 索引 | 创建／删除、异步重建、定义、目录和健康检查 |
| 任务与备份 | 筛选／查看／取消／重试；备份、恢复／演练、审计、恢复提交、修复、清理、GC 和自动备份状态／重置 |
| 数据接入 | 原子提交、采集批次、CSV／JSONL 导入、采集器／批次状态、死信／重放 |
| 治理与配置 | 来源策略、租户配置和存储用量 |
| 集群 | 分片注册／摘流／恢复／注销；租户分配／迁移／取消；路由摘流／恢复；私有 Raft 状态／升级／成员变更／交接／屏障／摘流／恢复 |
| 连接设置 | 分别配置数据、管理、路由及私有 Raft 入口与令牌 |

记录和操作回执使用分组属性、带类型的字段摘要、表格、状态，以及任务进度／时间线。
实体／模型编辑、写入、标签／元数据、任务参数和治理配置使用结构化表单，可添加字段
和数组项目。复杂及未知 API 字段可在折叠的高级 JSON 编辑器中处理，切换展示方式保留
已有值与大整数；字段重名或值与所选类型不符时阻止提交。原始 JSON 默认收起，查询语言
编辑器和显式 JSON 结果视图仍可使用。长弹窗单独滚动内容，标题和操作按钮始终可见。
控件、提示和说明为双语；API 标识符、自定义字段名
和原始数据保持原文。关系图只展示返回的数据，最多 100 个节点和 200 条边，不代表整个租户
的完整图。

折叠的响应详情、任务检查点和原始 JSON 在首次展开时渲染；查询结果仅生成选中的表格／JSON／图
视图。查询列表标签只读取对应 API，查看任务时读取最新详情而不重新加载整个列表。
表单输入校验在停止输入 150 ms 后合并执行；提交、导航和语言切换仍同步读取当前字段，
不会因等待校验而丢失编辑或提交旧值。

概览使用当前 API 快照，刷新或切换租户后更新：展示本地健康／就绪、数据文件系统的
已用／可用容量、当前租户最大的六类存储及其余分类合计、请求并发占用与实例上限
（排队数单独显示）、最近最多 100 个租户任务、已发布／可读／快照版本。
缺失或失败的观测显示不可用，有效空样本显示零；版本标签保留完整数值。
图表不表示历史吞吐趋势、采样范围以外的任务总数或整个集群健康。
点击“查看”在弹窗中打开原始响应，概览不铺开诊断文本列表。

## 连接与授权

合并监听器使用页面同源地址。分离监听器通过同源网关调用。
[网关示例](../deploy/nginx/graphdb.conf.example)将 `/admin/ui/` 静态资源转发到
`/ui/`；`/admin/v1/...` 仍要求 operator/admin 授权。数据入口填写网关地址，管理
入口填写 `<网关地址>/admin`。支持同源会话 Cookie 和输入的 Bearer 令牌。
跨域调用需要网关允许 CORS／预检及 `Authorization`、`Content-Type`、`X-Tenant-ID`、
`X-Raft-Cluster` 请求头；数据库不会新增宽松跨域策略。

控制台不新增认证系统、任意地址服务端代理或宽松角色，也不公开私有 API。
路由／Raft 令牌单独配置，Raft 还需集群 ID。私有接口只通过已授权管理网络或网关
供浏览器访问。需要限制 UI 本身访问时，在静态路由接入部署环境的会话登录。
详见[生产安全边界](security-deployment.zh-CN.md)。

入口、租户和语言保存于本地；令牌仅存于内存，刷新即清除。查询／接入草稿仅在
当前页面生命周期保留，配置编辑器放弃更改前会提示。各查询语言独立保留草稿，选择示例后
需点击“载入示例”才会替换编辑内容。接入标签保留有效草稿；字段或 JSON 未完成时阻止
切换，避免丢失内容。新增数组项目使用空白／默认值，不复制已有记录。标签支持方向键及
Home／End 切换。连接设置按基础 API 和可选路由／Raft 入口分组，已配置的集群入口自动展开。
请求不自动重试；超时后先核对
服务端状态。停止浏览器等待不保证服务端取消，请通过当前进程的运行中查询取消。

变更前展示目标和请求内容。破坏性操作要求输入资源 ID；恢复默认预演。
HTTP 202 表示受理，请查看任务／WAL 状态后再判断完成。原有部署及备份要求仍适用；
不支持的操作显示后端错误。

使用当前 Chrome，通过原生无损 JSON 保留 API 返回的大整数。这不能恢复后端数值字段
已经损失的精度，精度敏感的大字段值请按现有 API 使用字符串。浏览器导出使用内存，大规模导出
请使用 CLI 或流式 HTTP 客户端。

## 开发

源码 `internal/adminui/static/` 由 `go:embed` 内嵌，修改后重新构建并重启。

```sh
node --test internal/adminui/console_test.mjs
go test -mod=readonly ./internal/httpapi ./internal/sharding
```

页面／交互用本机 Chrome 验证，Linux 服务用 OrbStack 验证；静态检查不能替代运行验证。
